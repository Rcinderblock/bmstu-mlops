# MLOps: учебный проект

Один проект на весь семестр. ДЗ1: подготовка окружения, запуск готовой
языковой модели и измерение производительности компьютера.

## Установка окружения

Нужны `uv` и Python 3.12. Версия Python задана в `.python-version`,
требование к ней — в `pyproject.toml`.

Из корневой папки репозитория:

```bash
uv sync --locked
uv run --locked python --version
```

Первая команда создаёт `.venv/` и устанавливает библиотеки из `uv.lock`.
Параметр `--locked` проверяет соответствие файла фиксации текущему
`pyproject.toml` и не позволяет незаметно его пересоздать.

## Файлы проекта

| Путь | Назначение |
|---|---|
| `src/config.py` | Чтение настроек из `params.yaml` |
| `src/model.py` | Загрузка модели, подготовка запроса, генерация ответа |
| `src/generate.py` | Запуск генерации и печать ответа |
| `src/bench.py` | Измерение времени загрузки, скорости и пика памяти |
| `params.yaml` | Настройки модели, генерации и измерений |
| `pyproject.toml` | Требуемый Python и прямые зависимости с версиями |
| `uv.lock` | Точные версии полного набора зависимостей |
| `Makefile` | Короткие команды запуска |
| `tests/check.sh` | Самопроверка, выданная преподавателем |
| `data/`, `conf/` | Папки для развития проекта в следующих работах |
| `docs/` | Отчёты для сдачи; `hardware.md` появится после измерений |

## Команды ДЗ1

```bash
make install
make generate
make bench
make check
```

**Состояние работы:** окружение Python 3.12.12 подготовлено. Установлено
36 пакетов; проверены согласованность зависимостей, импорты библиотек
и модулей проекта. На Apple M3 выполнено проверочное умножение матриц
через графический ускоритель в форматах `float32` и `bfloat16`.
Модель из `params.yaml` запущена на M3 через `mps:0` в `bfloat16`:
два отдельных успешных запуска дали побайтово одинаковый вывод, по 71
новому токену. Второй запуск выполнен без доступа к Hugging Face,
с использованием локальных файлов модели.

Исправлены выбор модели из конфигурации, её имя в выводе и отчёте,
настройки повторяемости. Тот же загрузчик проверен на альтернативной
модели из самопроверки преподавателя: загрузка и короткая генерация успешны.

**Осталось:** исправить таймеры и добавить прогрев в `src/bench.py`,
получить три метрики, подготовить `docs/hardware.md` и выполнить полную
самопроверку. Пока `make bench` выдаёт некорректные измерения исходной
заготовки; результаты этого скрипта ещё не используются как замеры.

Первый запуск генерации скачивает файлы модели в локальное хранилище
Hugging Face; последующие запуски могут использовать скачанные файлы.
Веса модели в репозиторий не входят.
