# Русские команды личного планировщика

**ДЗ4: токенизация, единый шаблон чата, маска ошибки и форма батча.**
Диалоги о календаре, списках и будильниках преобразованы в последовательности
для будущего обучения модели. Веса модели на этом этапе не загружаются.

## Результат

- Обработаны **2743 обучающих и 352 проверочных примера**, без обрезки и потерь ответов.
- Из **426037** входных токенов train в ошибке обучения участвуют **8553 (2.01%)**:
  ответ и завершение. Промпт остаётся контекстом, его цели замаскированы.
- Единый шаблон: совпали **3095/3095** префиксов подготовки и генерации.
- Левое динамическое заполнение; первый батч **8 × 160**.
- Максимальная длина train **193**, предел **224**. Доля заполнителей — **5.74%**.

## Воспроизведение

Нужны Git, `uv` и Python 3.12. Из корня проекта:

```sh
make install           # точные версии из uv.lock
make fetch-data        # открытый источник и проверка контрольной суммы
make data              # все стадии, включая tokenize
make tokenize          # отдельно подготовка последовательностей
make check             # исходные 9 проверок преподавателя
make test              # дополнительные тесты и проверки сохранённых модулей
```

При первом запуске библиотека скачает токенизатор модели из `params.yaml`.
Веса для `make tokenize` и `make check` не нужны. При заполненном локальном
кэше можно запускать с `HF_HUB_OFFLINE=1`.

Отпечаток неизменённого `tests/check.sh`: **f2002c8c9519**.
Проверка сама вызывает `make tokenize`, затем сверяет сохранённые результаты.
Протокол: [hw04-check.txt](docs/results/hw04-check.txt).

## Файлы

| Файл или папка | Назначение |
|---|---|
| `data/train.jsonl`, `data/val.jsonl` | Диалоги: инструкция, запрос, правильная метка |
| `src/prompt.py` | Один шаблон для подготовки и генерации |
| `src/tokenize_data.py` | Граница ответа, маска, обрезка, измерения и отчёт |
| `src/collate.py` | Три массива одинаковой формы с заполнением слева |
| `data/tokenized/train.pt`, `val.pt` | Результаты на диске, отслеживаются DVC |
| `params.yaml` | Модель, длина, порог обрезки, размер батча и прогноз |
| `dvc.yaml`, `dvc.lock` | Зависимости стадий и контрольные суммы |
| `metrics/tokenize.json` | Машиночитаемые измерения |
| `docs/tokenize_report.md` | Автоматически создаваемый отчёт |
| `docs/defects.md` | Причины четырёх дефектов и числа до/после |
| `scripts/probe_tokenization.py` | Контрольный опыт с недостаточной длиной |

Необязательная упаковка нескольких диалогов в одну строку отключена.
Прогноз времени — условная оценка от измеренной скорости генерации;
реальное обучение не проводилось. Малое число обучающих позиций объясняется
классификацией: ответ содержит только одну из девяти коротких меток.

## Данные и версии

Источник — русский [MASSIVE 1.0](https://github.com/alexa/massive), Amazon,
[CC BY 4.0](docs/MASSIVE-LICENSE.txt), основанный на [SLURP](https://arxiv.org/abs/2011.13205).
Отобраны команды личного планировщика, удалены повторы и сомнительная разметка,
добавлены инструкции, выполнено разделение по группам шаблонов.
[Паспорт](docs/datasheet.md) описывает происхождение и ограничения.
Согласование темы преподавателем не зафиксировано.

Данные исключены из Git. DVC-хранилище расположено рядом с проектом,
в `../MLOps-dvc-store`; на другом компьютере этой локальной папки нет.
Для восстановления достаточно `make fetch-data` и `make data` либо
`uv run --locked dvc pull` при наличии доступа к заполненному хранилищу.

Сохранены метки `hw03-v1`, `hw03-v2`, команды `make diff`, `make check-hw3`,
[разбор подготовки данных](docs/hw03-defects.md) и [обзор](docs/hw03-overview.md).
Доступны также `make generate`, `make bench`, `make inspect`, `make check-hw1`,
`make check-hw2`; отчёты [hardware.md](docs/hardware.md) и [anatomy.md](docs/anatomy.md).
Лекции, заметки, данные, окружение, голос и рабочие видеозаписи в Git не включаются.
