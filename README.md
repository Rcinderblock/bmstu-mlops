# MLOps: учебный проект

Один репозиторий на весь семестр. ДЗ1: окружение, запуск готовой языковой
модели и измерение производительности компьютера.

## Быстрый запуск

Нужны `uv` и Python 3.12. Из корневой папки репозитория:

```bash
make install
make generate
make bench
make check
```

`make install` устанавливает точные версии из `uv.lock` в `.venv/`.
Первый запуск скачивает модель из Hugging Face. Когда обе модели
(основная и альтернативная из проверки) скачаны, можно работать без сети:

```bash
HF_HUB_OFFLINE=1 make generate
HF_HUB_OFFLINE=1 make bench
HF_HUB_OFFLINE=1 make check
```

## Файлы и команды

| Путь | Назначение |
|---|---|
| `src/config.py` | Чтение `params.yaml` |
| `src/model.py` | Загрузка модели, шаблон запроса, общая генерация |
| `src/generate.py` | Печать ответа и фактического числа новых токенов |
| `src/bench.py` | Отдельные таймеры, прогрев, медиана скорости и пик памяти |
| `params.yaml` | Имя модели, устройство, формат чисел и параметры запуска |
| `.python-version` | Python 3.12 |
| `pyproject.toml`, `uv.lock` | Точные версии зависимостей |
| `tests/check.sh` | Пять критериев ДЗ1, с контролем ошибок и восстановлением настроек |
| `tests/test_bench.py` | Пять проверок правильности измерений, без скачивания модели |
| `docs/hardware.md` | Итоговый отчёт и разбор четырёх дефектов |
| `docs/results/` | Сохранённые результаты и протоколы проверок |
| `data/`, `conf/` | Папки для следующих заданий |

`make test` отдельно выполняет пять тестов измерений. `make check` также
проверяет загрузку альтернативной модели и совпадение двух успешных
запусков генерации. На время проверки изменяется `params.yaml`, после
проверки исходное содержимое восстанавливается.

`make bench` печатает короткую сводку и сохраняет полные данные каждого
прогона в `docs/bench.json`. Этот временный файл не перезаписывает
сохранённый результат `docs/results/hw01-bench.json`.

## Результат ДЗ1

На Apple M3 с 16 ГиБ памяти, Python 3.12.12, устройство `mps:0`, `bfloat16`:

- Загрузка модели и токенизатора из локальных файлов: **1.698473 с**.
- Медиана трёх генераций после одного прогрева: **38.452372 токена/с**.
- Максимальная RSS-память процесса: **1145.6 МиБ**.
- Два успешных запуска дают побайтово одинаковый ответ, по 71 новому токену.
- Все пять критериев исходного скрипта преподавателя пройдены.
- Усиленная проверка и пять тестов измерений пройдены.

Условия, ограничения метрик и исправления:
[итоговый отчёт](docs/hardware.md).

и веса модели в репозиторий не включены.
