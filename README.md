# Русские команды личного планировщика

ДЗ3: подготовка данных для классификации запросов к календарю, спискам и будильникам.
Задача — собрать более 1000 примеров, очистить их, разделить без пересечений,
сохранить две версии в DVC и проверить изменения. Обучение модели в эту работу не входит.

## Полученный результат

**3455 очищенных примеров**, девять действий, четыре инструкции, 3290 групп.
Train / val / test: **2743 / 352 / 360**. Обнаруженных пересечений между
выборками — **0** по всем четырём проверяемым признакам. Версия v2 добавила
1014 примеров к v1. Паспорт: [datasheet.md](docs/datasheet.md),
исправления: [defects.md](docs/defects.md), [обзор для сдачи](docs/overview.md).

## Запуск

Нужны `uv`, Python 3.12 и Git. Команды выполняются из корня проекта.

```sh
make install          # установить точные версии из uv.lock
make fetch-data       # скачать открытый источник и проверить SHA-256
make data             # сборка → очистка → разнообразие → разбиение → проверка утечек
make check            # восемь проверок задания
make test             # тесты исправлений и сохранённых модулей проекта
```

`make fetch-data` нужен один раз. Он загружает MASSIVE 1.0 с официального сервера
и извлекает только русский JSONL и лицензию. Повторный запуск проверяет хеш.
Если локальное хранилище DVC уже заполнено, можно вместо загрузки выполнить
`uv run --locked dvc pull`. Хранилище расположено рядом с проектом в
`../MLOps-dvc-store`; на другом компьютере этой папки изначально нет.

## Версии

`v1` использует исходную часть `train`. `v2` добавляет исходные `dev` и `test`.
После очистки выполняется собственное разбиение по шаблонам. Это новый учебный
корпус, его метрики нельзя сравнивать с официальным результатом MASSIVE.

```sh
uv run --locked python scripts/set_version.py v1
make data
uv run --locked python scripts/set_version.py v2
make data
make diff             # dvc metrics diff между метками hw03-v1 и hw03-v2
uv run --locked dvc push
```

## Источник и ограничения

[MASSIVE](https://github.com/alexa/massive), Amazon, русский язык, версия 1.0,
[CC BY 4.0](docs/MASSIVE-LICENSE.txt). Работа перерабатывает исходные данные:
выбирает предметную область, отсеивает спорную разметку и таймеры, создаёт
инструкции и группы по шаблонам, удаляет повторы и делает новое разбиение.
Источник основан на [SLURP](https://arxiv.org/abs/2011.13205);
[публикация MASSIVE](https://arxiv.org/abs/2204.08582).

Нулевые пересечения означают отсутствие найденных совпадений идентификаторов,
нормализованных текстов, шаблонов и словных шинглов при заданном пороге.
Это не доказательство отсутствия всех смысловых парафразов и не оценка модели.
Согласование темы преподавателем не зафиксировано.
