# Русские команды личного планировщика — ДЗ6+7

Один проект на семестр. Текущий этап: шесть коротких LoRA-экспериментов,
выбор кандидата по ошибке и отдельная проверка качества его ответов.
Код подготовлен; результаты будут опубликованы после реальных запусков.

Условия оценки закреплены в [протоколе](docs/evaluation-protocol.md).
`evaluation/solution.py` считает результаты по всем вопросам и проверяет
отсутствие ухудшения. `src/sweep.py` создаёт отдельные запуски MLflow.
`compose.yaml` хранит базу и файлы в двух постоянных томах.

Основной маршрут: `make install`, `make up`, `make data`, `make check-eval`,
`make sweep`, `make report`, `make candidate`, `make baseline-init`,
`make evaluate`, `make eval`, `make check-negative`, `make check-storage`,
`make check-all`. `make promote` выполняется только после PASS по качеству.
Отказ кандидату допустим и не мешает остальным проверкам.

MLflow доступен на http://127.0.0.1:5006. `make down` останавливает сервер,
сохраняя тома. Не удаляйте volumes для обычной остановки.

Исходные проверки преподавателя сохранены без изменений: `c42ac7788026`.
Прежние тесты лежат в `tests/legacy/`; их модульные проверки доступны через
`make test-legacy`. Исторические проверки полного запуска следует выполнять
в копии соответствующего коммита, чтобы не смешивать стадии семестра.

Материалы преподавателя, заметки, данные, веса, окружение, голос и видео
не входят в Git. Данные проверки будут доступны отдельным приложением.
