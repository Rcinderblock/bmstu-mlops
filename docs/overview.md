# ДЗ4 — обзор результата

## Задание

Подготовить диалоги для будущего обучения языковой модели:
**токены → шаблон чата → маска ошибки → батч**.

Тема: русские команды личного планировщика — календарь, списки, будильники.
Ответ: одна из девяти меток действия.

Исправлены четыре дефекта заготовки. Входные файлы — `data/train.jsonl`
и `data/val.jsonl`. Результат — `data/tokenized/train.pt` и `val.pt`.
На этом этапе загружается только токенизатор; обучение модели не выполняется.

## Обрезка и запас

| Проверка | train | val |
|---|---:|---:|
| Максимальная длина | 193 | 185 |
| Основной предел | 224 | 224 |
| Обрезано при 224 | 0 / 2743 | 0 / 352 |
| Контрольный предел | 160 | 160 |
| Обрезано при 160 | 552 / 2743 (20.12%) | 75 / 352 (21.31%) |
| Без обучающих позиций при 160 | 314 | 49 |

Порог — 5%. Основной набор проходит; контрольный опыт обнаруживает превышение.
Все доли считаются по входным строкам, включая впоследствии удалённые.

Измерения: `metrics/tokenize.json`, `docs/results/hw04-short-limit.json`.
Контрольный запуск не меняет основную конфигурацию и сохранённые массивы.


отсутствие служебных строк в коде, левое заполнение, доля обрезанных,
склейка на границе токенов, стадия DVC, разбор дефектов и состав Git.
