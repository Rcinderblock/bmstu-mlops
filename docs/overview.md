# ДЗ5 — первый запуск обучения

## Задание

Обучить небольшие добавочные матрицы к Qwen3-0.6B на русских командах
личного планировщика: календарь, списки и будильники. Выполнить два полных
варианта, сравнить ошибку, время и память. Сохранить переносимый адаптер,
проверить повторяемость и разобрать пять дефектов.

## Входные файлы

| Файл | Что содержит | Примеры |
|---|---|---:|
| `data/tokenized/train.pt` | Числа, маска внимания, правильные метки для обучения | 2743 |
| `data/tokenized/val.pt` | Примеры для проверки без изменения весов | 352 |

Модель читает весь контекст. Ошибка считается только на ответе и завершении.
Максимальная реальная длина — 193 токена, установленный предел — 224.
За одну эпоху обработаны все 426037 входных токенов обучения.

## Настройки обучения

| Настройка | Значение |
|---|---|
| Модель и устройство | Qwen3-0.6B, Apple M3, MPS |
| Точность базовых / обучаемых весов | bfloat16 / float32 |
| Размер добавочных матриц | r=8, alpha=16, семь проекций |
| Шаг изменения весов | 0.0002 |
| Случайность | seed=42, dropout=0.05 |
| Батч | 8 примеров × 1 обновление, эффективный размер 8 |
| Продолжительность | Одна полная эпоха, 343 обновления, max_steps=null |
| Проверка ошибки | До обучения, каждые 10 шагов и в конце |

Замороженные первые слои продолжают читать запрос, но их веса не изменяются.
Матрицы словаря и выходного словаря в адаптер не включены.

## Сравнение вариантов

| Измерение | Все 28 слоёв | Только последние 14 |
|---|---:|---:|
| Обучаемые параметры | 5,046,272 | 2,523,136 |
| Доля параметров с адаптером | 0.84% | 0.42% |
| Шаги обновления | 343 | 343 |
| Ошибка до обучения | 1.236143 | 1.236143 |
| Ошибка после обучения | 0.067542 | 0.102787 |
| Обучение, без оценки | 2062.4 с | 1872.1 с |
| Начальная и последующие оценки | 2040.9 с | 1865.9 с |
| Обучение вместе с оценкой | 4103.2 с | 3738.0 с |
| Наблюдаемая память MPS | 2347.8 МиБ | 2339.9 МиБ |
| Папка адаптера и токенизатор | 30.20 МиБ | 20.55 МиБ |

Скорость и память измерены по одному запуску каждого варианта на одном
ноутбуке. Память — выборочные замеры `torch.mps.driver_allocated_memory`,
включая оценку, а не вся память системы. Время исключает загрузку модели
и сохранение файлов. Меньшая ошибка означает лучшее предсказание правильных
токенов; она не равна доле правильно распознанных команд.

## Пять исправлений

| Дефект | Исправление | Подтверждение |
|---|---|---|
| Нет проверки на отложенных данных | Замер до обучения и по ходу | 1.236143 → 0.067542 |
| Слишком большой шаг изменения весов | 0.01 → 0.0002 | Ошибка падает, расхождения нет |
| Заморозка только на словах | Матрицы только в слоях 14–27 | 5,046,272 → 2,523,136 |
| Неполная папка адаптера | Токенизатор и шаблон рядом с весами | Проверка загрузки без сети и пять тех же ответов |
| Разные повторные запуски | Случайность закреплена до создания матриц | Два независимых процесса по три шага |

Подробности, ограничения измерений и числа — в `docs/defects.md`.

## Переносимость

| Папка или файл | Назначение |
|---|---|
| `models/adapter_all_layers/adapter_model.safetensors` | Обученные матрицы, 19.30 МиБ |
| `adapter_config.json` | Размер, проекции, слои и имя базовой модели |
| `tokenizer.json`, `tokenizer_config.json`, `chat_template.jinja` | Преобразование текста и оформление диалога |
| `training_metadata.json` | Настройки подготовки и отпечаток входов |

Для загрузки без сети базовые веса должны уже быть в локальном кэше.
Проверка копирует папку адаптера во временный каталог и сравнивает ответы.
Это проверка изолированной папки на этом ноутбуке, а не запуск на физически
другом компьютере. Загрузка базы с интернета ей не требуется.

## Проверка

Запуск: `make check`. Все девять проверок прошли.
Неизменённый скрипт преподавателя: **06a02208c1f0**.
Проверка не обучает полный вариант повторно: она проверяет сохранённые
результаты, загружает копию адаптера и обучает дважды по три шага.
Дополнительно прошли 40 тестов, включая заморозку, маску и градиенты.
