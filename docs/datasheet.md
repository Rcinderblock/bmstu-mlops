# Паспорт данных: русские команды планировщика

Источник: MASSIVE 1.0 (Amazon), русский язык, CC BY 4.0; ссылка и SHA-256 —
в `conf/source.json`, текст лицензии — `docs/MASSIVE-LICENSE.txt`.
Задача: по команде пользователя выбрать одно из девяти действий календаря,
списков или будильника. Обучение модели на этом этапе не выполняется.

Версия v1: 2508 строк после отбора, 2441 после очистки; 2347 групп шаблонов.
Train / val / test: 1925 / 256 / 260. Во всех выборках есть девять классов.
Нулевые пересечения по id, нормализованным текстам, группам и словным
четырёхграммам при Жаккаре ≥ 0.85 подтверждены для всех трёх пар.

Выполнены сужение области, проверка голосов разметчиков, устранение
противоречивых меток, исключение таймеров, проверка восстановления текста
из разметки слотов, добавление четырёх инструкций, группировка по шаблонам.
Значения слотов заменяются их типами, затем каркас хешируется в `topic`.
Кодировка: UTF-8, формат: JSONL, роли: system → user → assistant.

Длины запросов в символах: p50=40, p90=67, p99=100, максимум=148.
Минимум 5 символов сохраняет короткие команды. Ответы — фиксированные
метки: их повторы ожидаемы. Проверяем 9 классов, максимум 40% одного класса,
p90/p10 длин запросов ≥ 2, отсутствие точных повторов запросов, минимум
1000 примеров, 3 инструкции и 50 групп, максимум 10% одной группы.

Ограничения: переведённые одношаговые команды, нет истории диалога,
не выполняются реальные действия, качество модели не измерялось.
Фильтры ПДн покрывают телефоны, email и явно указанные даты рождения;
это не полное обезличивание. Нулевые счётчики не заменяют эту оговорку.
Разделение по шаблонам и лексическим шинглам не гарантирует отсутствия
всех смысловых парафразов. Согласование темы преподавателем не зафиксировано.
