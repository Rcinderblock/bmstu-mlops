# ДЗ3 · подготовка данных

## Задание

Подготовить **свой датасет для будущего дообучения**:

- минимум 1000 очищенных примеров в формате диалога;
- очистка и проверки, которые останавливают обработку при ошибках;
- разделение на обучение, валидацию и тест без обнаруженных пересечений;
- две версии данных в DVC и сравнение измерений;
- паспорт данных и разбор пяти дефектов.

**Тема:** русские команды личного планировщика.
Календарь · списки дел · будильники. Девять действий.

**Результат:** 3455 примеров, две версии, восемь проверок пройдены.
Модель на этом этапе не обучалась.
